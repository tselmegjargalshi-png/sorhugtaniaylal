# Сорхугтани Аялал — Монгол аялал жуулчлалын вэбсайт

Монголыг 3D, хөдөлгөөнт дизайнаар танилцуулах аялал жуулчлалын сайт: Улаанбаатар, 21 аймаг (УБ-аас зай, үзэх газрууд), дөрвөн улирал, баяр наадам, үндэсний хоол, хэл, цаг агаар, валют, зөвлөгөө болон сагстай аяллын багцууд.

Хэл: монгол, English, 한국어, 日本語, 中文, Türkçe, Русский.

- `npm install` → `npm run dev` (локал), `npm run build` (production)
- Технологи: Vite, three.js, GSAP ScrollTrigger, Lenis
- Зургууд: Wikimedia Commons (зураг бүр дээр зохиогч, лиценз бичигдсэн)
- Газрын зураг: geoBoundaries (CC BY 4.0)

«Сорхугтани Аялал» нь зохиомол компани, утас болон захиалгын маягт нь жишээ зорилготой.
